# MobileArmor (TrustCore-SDK) 🛡️

**Enterprise-Grade Zero-Trust Mobile App Protection SDK**

MobileArmor provides real-time runtime application self-protection (RASP), memory encryption, and hardware-attested environment integrity checks for high-security iOS and Android applications.

## ⚠️ IMPORTANT: Licensing & Commercial Use
MobileArmor strictly follows a **Dual-Licensing (Open-Core)** model. 
* **Community Edition (AGPLv3):** Free and open-source. If you include this in a closed-source app, you are legally required to open-source your entire application.
* **Enterprise Edition (Commercial):** Purchase a commercial license via [Polar.sh](https://polar.sh/mobilearmor) to legally use this SDK in closed-source applications.
